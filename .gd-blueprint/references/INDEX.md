# Reference Index

Use this directory for cited research and reference-only media. It is outside Unity's
`Assets` directory so references are not imported into the game accidentally.

## Rules

- Add an entry for every research source and local reference file used in planning.
- Prefer the original source URL. Record the creator or publisher when known and use an
  ISO access date (`YYYY-MM-DD`).
- Copy media here only when it is user-provided, generated for this project, or its
  license or explicit permission allows copying. Otherwise, keep only the URL and notes.
- A rights note records the known basis for use; it is not a claim of ownership. Mark
  uncertain rights as `Unknown - link only` and do not save a local copy.
- Use stable names such as `REF-001-short-description.ext` and keep large files under the
  repository's existing storage policy. Do not install or configure Git LFS implicitly.
- Moving a reference into `Assets` as a production asset requires a deliberate decision,
  suitable usage rights, and the normal Unity asset and `.meta` safeguards.
